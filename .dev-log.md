## 2026-10-17

### Added (Bluesky tab)
- Why: Reddit blocks requests that aren't logged in. I tested other free sources: Bluesky worked with no login and had about 100 Lakers posts a day. Reddit RSS was rate-limited (429) after a few requests. Mastodon and Lemmy had little NBA fan activity.
- `app.py`: `/api/buzz?team=<full name>` searches Bluesky for the quoted full team name (plain "Heat" or "Kings" pulled in unrelated posts), English only, from the last 24 hours. It widens to 3 days if there are fewer than 10 posts, returns the top 25 by likes + 2×reposts, and caches for 2 minutes. It skips authors who set Bluesky's `!no-unauthenticated` label (they asked not to be shown to logged-out viewers).
- `index.html`: new **Bluesky** tab between Fan Talk and Memes, with avatar, name, post text, image thumbnails, like/repost/reply counts and a link to the post.
- Tested: Lakers 25 posts, Kings 22, Hornets 9 (the 3-day fallback kicked in).

### Added (Reddit login)
- `app.py`: new `reddit()` helper. When `.env` has `REDDIT_CLIENT_ID` and `REDDIT_CLIENT_SECRET`, it logs in with Reddit's app-only OAuth, keeps the token until it expires, and calls `oauth.reddit.com`. Without keys it falls back to the public `.json` URLs, as before. `/api/fans` and `/api/memes` now use it.
- `app.py`: small `.env` loader (no new dependency). User-Agent now follows Reddit's required format and includes `REDDIT_USERNAME`.
- `.env.example`: template for the three Reddit settings.
- `README.md`: setup step 4 (create a Reddit app), plus updated data sources, known issues and troubleshooting.
- Tested: without keys, Fan Talk and Memes still return the old 403 and every other endpoint still works. With fake keys, Reddit's login endpoint returns 401, which shows the OAuth path is wired. Not yet tested with real keys.

### Decisions
- Staying with **Flask + plain HTML/JS** for the web app instead of the Streamlit plan. Reason: a live fan page needs feeds that refresh on their own, and the existing Flask setup already does that. Streamlit could come later as a separate analytics page.
